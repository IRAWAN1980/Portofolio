Core capabilities

One platform, three assessment modules

Each engine is an independent adapter — if one engine fails, results from the others are kept.

Module 01

Web Application Security Assessment

  • OWASP Top 10 engine with 50+ test cases in three phases: recon → automated → manual checks.
  • Evidence Gate: only proven findings reach the report — guessed paths (404/403) are dropped and 200 responses are re-validated.
  • Path-lock & scan profiles (Quick / Full / Compliance) — target a single path or a whole domain.
  • Scan safety: cooperative cancel, default throttling and automatic pause on 5xx errors.
  • PoC enrichment with multiple reproducible curl proofs per finding.

Module 02

Network Vulnerability Assessment

  • Modular adapters: Nmap (conservative profile), testssl.sh and Greenbone / GVM.
  • Readiness & feed freshness shown in Scanner Management — no silent auto-install or auto-sync.
  • Host discovery, port and service/version detection — open ports are treated as attack surface, not as proof of vulnerability.

Module 03

PHP2Shell Check & Web Tech Discovery

  • Dedicated check for PHP applications: identifies file-upload-to-web-shell paths and web-shell exposure.
  • Web Tech Discovery detects PHP/CMS on domains and subdomains, versions and end-of-life status, ownership and takeover candidates.
  • Results flow into the same unified finding schema as the web and network modules.

Governance

Scope, Authorization & Access

  • Engagement + RoE: every target stores the asset owner, authorization number, approving PIC, time window and exclusions.
  • Expiry enforced — scans are rejected when authorization has expired, and re-checked before execution.
  • 4-role RBAC with multi-tenant isolation (cross-tenant access returns 404 to prevent enumeration).
  • Mandatory TOTP MFA for privileged roles, brute-force lockout and one-time recovery codes.

Intel & Report

Risk Intelligence & Reporting

  • KEV / EPSS / NVD enrichment for risk-based prioritization.
  • Unified finding schema with de-duplication — validation status and remediation status are tracked separately.
  • Report Center: consultant-grade PDF/HTML — cover, executive summary, attack surface, consolidated findings and remediation roadmap, plus retest.
  • Dynamic organization branding — logo and identity are changed from Settings, without code changes.

Deep dive

Safe-by-design scanning

Scanning other people's systems is only acceptable with clear authorization, so the platform enforces scope at every step — not only when a job is created.

Target wizard → scope validation
→ job queued → authorization re-check
→ engine execution → raw findings
→ evidence gate → ingest & report
deny-by-default scope managed egress anti-SSRF / DNS rebinding

Engineering principles

  • Scope is validated at creation and again before execution.
  • Idempotent, non-destructive data migrations that stay compatible with existing data.
  • Scheduled backups with tested restore and rollback drills.
  • Secrets never appear in source code, logs or API responses.
  • Tamper-evident audit trail for user and scan activity.
